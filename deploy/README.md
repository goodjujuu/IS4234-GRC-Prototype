# Deploy (placeholder)

The course requires the technology demonstrator to be hosted on an appropriate online platform
with a working, accessible link (not just runnable locally). Pick whatever's easiest for the
chosen stack — e.g. a simple free-tier host for a Next.js + small API app, or a container
platform if the team ends up close to the `is4228` project's Docker/Cloud Run setup.

Whatever is chosen, document here:

- Where it's hosted and the live link
- How to redeploy after a change
- Any environment variables the hosted version needs (do not commit real secrets — use
  `.env.example` as the template and set real values in the host's config instead)
